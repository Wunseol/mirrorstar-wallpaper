## 4. 功能需求分析

### 4.1 Lively Wallpaper 功能全景

以下为 Lively Wallpaper 的完整功能列表及其在 MirrorStar 中的取舍决策：

### 4.2 保留功能

| 功能 | 说明 | 保留理由 |
|------|------|----------|
| 视频壁纸 | 通过 mpv 播放视频文件作为壁纸 | 核心功能，用户最常用的壁纸类型 |
| GIF 壁纸 | 播放 GIF 动图作为壁纸 | 核心功能，轻量级动态壁纸 |
| 网页壁纸 | 通过 WebView2 渲染网页作为壁纸 | 核心功能，支持 Shadertoy、网页动画等丰富内容 |
| 静态图片壁纸 | 设置静态图片为壁纸 | 基础功能，用户期望的最低支持 |
| 桌面集成 | 通过 WorkerW 将壁纸嵌入桌面 | 技术核心，实现壁纸在桌面图标下方显示 |
| 多显示器支持 | 为不同显示器设置不同壁纸 | 实用功能，多显示器用户刚需 |
| 暂停/恢复 | 检测全屏应用自动暂停壁纸 | 性能关键，游戏/全屏应用时释放资源 |
| 系统托盘 | 最小化到系统托盘运行 | 壁纸软件必备，后台运行不占任务栏 |
| 配置管理 | 保存和加载用户设置 | 基础功能，持久化用户偏好 |
| 拖放设置壁纸 | 拖拽文件到窗口设置壁纸 | 易用性功能，降低操作门槛 |

### 4.3 去除功能

| 功能 | 去除理由 |
|------|----------|
| Unity 壁纸 | 用户群体极小，Unity 运行时体积庞大（>100MB），与轻量化目标严重冲突 |
| Godot 壁纸 | 用户群体极小，Godot 运行时体积较大，与轻量化目标冲突 |
| BizHawk 模拟器壁纸 | 极其小众的需求，模拟器依赖复杂，维护成本极高 |
| YouTube/流媒体壁纸 | 依赖 youtube-dl/yt-dlp 等外部工具，网络流媒体增加复杂度和资源消耗，用户可直接下载视频后使用视频壁纸 |
| 壁纸创建器 | 非核心功能，用户可使用外部工具（如 VS Code、Shadertoy）创建壁纸内容 |
| 自动更新 | 安全风险（供应链攻击），增加复杂度，用户可手动更新或通过包管理器更新 |
| 多语言国际化 (i18n) | v1 版本 UI 仅支持中文界面（简体中文），代码结构预留 i18n 扩展点；如用户需求强烈，后续版本添加英文和多语言支持 |
| 壁纸库 GIF 预览 | GIF 预览需要解码并缓存帧数据，内存占用高；改用静态缩略图 |
| 按进程应用程序规则 | v1 过度设计，全屏检测暂停已覆盖主要场景；按进程规则可后续版本添加 |

## 5. 功能性需求

### 5.1 壁纸管理

| 需求 ID | 需求名称 | 优先级 | 描述 |
|---------|----------|--------|------|
| FR-001 | 视频壁纸播放 | P0 | 支持通过外部 mpv.exe 子进程播放 MP4/AVI/MKV/WebM/MOV/FLV 等常见视频格式作为动态壁纸，支持硬件加速解码（mpv --hwdec=auto）。mpv.exe 通过命名管道（mirrorstar-mpv-{uuid}）接收 mpv 原生 JSON IPC 命令控制 |
| FR-002 | GIF 壁纸播放 | P0 | 支持播放 GIF 动图作为动态壁纸，支持 GIF 循环播放 |
| FR-003 | 网页壁纸渲染 | P0 | 支持通过 WebView2 渲染 HTML/CSS/JavaScript 网页作为壁纸，支持本地网页文件和 URL |
| FR-004 | 静态图片壁纸 | P0 | 支持设置 JPG/JPEG/PNG/BMP/TIF/TIFF/DIB/WebP 等静态图片为壁纸。JPG/JPEG/PNG/BMP/TIF/TIFF/DIB 使用 Windows 原生壁纸 API（SystemParametersInfoW + 注册表），零资源占用，无需 WorkerW 嵌入；WebP 格式因系统原生不支持，回退到 WorkerW 渲染路径 |
| FR-005 | 壁纸切换 | P0 | 支持在已添加的壁纸之间切换，切换过程平滑无闪烁（切换期间桌面无黑屏闪烁，旧壁纸保持显示直到新壁纸就绪） |
| FR-006 | 壁纸删除 | P1 | 支持从壁纸库中移除壁纸，可选是否删除源文件 |
| FR-007 | 壁纸信息显示 | P2 | 显示壁纸的文件名、类型、分辨率、文件大小等基本信息 |
| FR-034 | 壁纸缩放模式 | P1 | 支持壁纸的缩放/适配模式设置，包括：填充（Fill，裁剪适配）、适应（Fit，保留黑边）、拉伸（Stretch）、居中（Center）、原始大小 |

### 5.2 桌面集成

| 需求 ID | 需求名称 | 优先级 | 描述 |
|---------|----------|--------|------|
| FR-008 | WorkerW 桌面嵌入 | P0 | 将壁纸窗口嵌入 Windows 桌面的 WorkerW 层，使壁纸显示在桌面图标下方。仅动态壁纸（视频/GIF/网页）和 WebP 静态图片需要 WorkerW 嵌入；JPG/JPEG/PNG/BMP/TIF/TIFF/DIB 静态壁纸使用 Windows 原生 API，无需 WorkerW |
| FR-009 | 壁纸窗口定位 | P0 | 壁纸窗口精确定位到桌面工作区，覆盖整个桌面背景区域。WorkerW 异步初始化（后台线程），不阻塞启动流程 |
| FR-010 | 桌面图标交互 | P0 | 壁纸运行时，桌面图标仍可正常点击、选择、拖动 |
| FR-035 | Explorer 重启检测 | P1 | 检测 Windows Explorer 重启事件，自动重新嵌入壁纸窗口到新的 WorkerW 层 |
| FR-039 | DPI 缩放适配 | P1 | 壁纸窗口在 Per-Monitor DPI V2 模式下正确显示，支持不同 DPI 缩放比例的多显示器环境，DPI 变更时自动调整壁纸尺寸 |

### 5.3 多显示器

| 需求 ID | 需求名称 | 优先级 | 描述 |
|---------|----------|--------|------|
| FR-011 | 多显示器识别 | P0 | 自动检测并列出系统中所有连接的显示器 |
| FR-012 | 独立壁纸设置 | P0 | 支持为每个显示器独立设置不同的壁纸 |
| FR-013 | 显示器热插拔 | P1 | 支持显示器热插拔事件的检测和自动适配 🔧 未实现，未来改进（当前需重启程序检测显示器变更） |
| FR-014 | 跨显示器壁纸 | P2 | 可选将单个壁纸跨所有显示器拉伸显示 |

### 5.4 暂停与恢复

| 需求 ID | 需求名称 | 优先级 | 描述 |
|---------|----------|--------|------|
| FR-015 | 全屏应用检测 | P0 | 检测到全屏应用（如游戏、全屏视频）运行时自动暂停所有壁纸（通过 pause_all_fast 实现），退出全屏时恢复所有壁纸。注：当前为全局暂停，按显示器独立暂停为未来改进项 |
| FR-016 | 手动暂停/恢复 | P0 | 支持用户手动暂停和恢复壁纸播放 |
| FR-017 | 暂停时静态帧 | P1 | 壁纸暂停时显示当前帧的静态画面，而非黑屏或隐藏 |
| FR-018 | 音频暂停 | P1 | 壁纸暂停时同步静音，恢复时恢复音量 |
| FR-032 | 电池供电暂停 | P2 | 检测到系统切换到电池供电时自动暂停壁纸播放（需用户在设置中启用），接通电源后自动恢复 |

### 5.5 系统托盘

| 需求 ID | 需求名称 | 优先级 | 描述 |
|---------|----------|--------|------|
| FR-019 | 托盘图标 | P0 | 程序启动时仅创建系统托盘图标，不创建主窗口。托盘菜单文本切换暂停/恢复状态（图标本身不随状态变化，仅菜单项文本反映当前状态）。主窗口按需创建：用户点击托盘图标时创建窗口，关闭窗口时隐藏窗口（hide）以保留 WebView2 实例（与 FR-021 一致），WebView2 延迟创建 |
| FR-020 | 托盘菜单 | P0 | 右键托盘图标弹出菜单，仅包含 3 项：打开（打开主窗口，按需创建 WebView2 窗口）、暂停壁纸/恢复壁纸（切换壁纸播放状态）、退出。注：更丰富的托盘菜单（音量控制子菜单、显示器壁纸信息子菜单、开机自启开关）为未来改进项 |
| FR-021 | 关闭隐藏窗口 | P0 | 关闭主窗口时隐藏窗口（hide）以保留 WebView2 实例，便于快速恢复；通过 `prevent_close + hide()` 实现。再次打开时直接 show，无需重新创建 WebView2 |
| FR-022 | 开机自启 | P1 | 支持设置开机自动启动（通过写入 HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run 注册表键实现，无需管理员权限） |
| FR-040 | 单实例运行 | P0 | 程序同时只能运行一个实例，重复启动时提示"镜星壁纸已在运行中"并退出新实例（通过 Windows 命名互斥体实现） |

### 5.6 配置管理

| 需求 ID | 需求名称 | 优先级 | 描述 |
|---------|----------|--------|------|
| FR-023 | 配置持久化 | P0 | 用户设置（当前壁纸、音量、暂停策略等）持久化保存，重启后恢复 |
| FR-024 | 壁纸库管理 | P0 | 维护用户添加的壁纸列表，包含壁纸路径、类型、缩略图等信息 |
| FR-025 | 音量控制 | P1 | 支持调节视频/网页壁纸的音频音量，包括全局静音 |
| FR-026 | 播放速度 | P2 | 支持调节视频和 GIF 壁纸的播放速度（默认 1.0 倍速，范围 0.25~4.0）。视频壁纸通过 mpv IPC set_speed 命令实现；GIF 壁纸通过 GifCommand::SetSpeed 调整定时器间隔（delay_ms / speed，最小 10ms）实现 |
| FR-027 | 配置文件路径 | P2 | 配置文件存储在 `%APPDATA%/mirrorstar/` 目录下 |
| FR-036 | 壁纸搜索 | P2 | 支持按文件名在壁纸库中搜索壁纸 |
| FR-037 | 配置热重载 | P2 | 支持配置文件的热重载，用户通过外部编辑器修改配置文件后，程序自动检测变更并应用新配置（部分配置项立即生效，部分需重启） |
| FR-038 | WebView2 数据目录管理 | P2 | 每个 WebView2 壁纸实例使用独立的用户数据目录，壁纸关闭时可选保留数据，壁纸删除时清理对应数据目录，定期清理超过 30 天未使用的数据目录 🔧 未实现，未来改进（WebConfig.cache_path 字段已定义但未使用，WebView2 使用默认数据目录） |

### 5.7 用户交互

| 需求 ID | 需求名称 | 优先级 | 描述 |
|---------|----------|--------|------|
| FR-028 | 拖放添加壁纸 | P0 | 支持将文件从资源管理器拖放到主窗口来添加壁纸 |
| FR-029 | 文件选择添加 | P0 | 支持通过文件选择对话框添加壁纸文件 |
| FR-030 | 壁纸缩略图 | P1 | 壁纸库中显示壁纸的静态缩略图（视频取首帧，GIF 取首帧，网页显示默认缩略图） |
| FR-031 | 鼠标穿透 | P2 | 可选开启壁纸的鼠标穿透模式，使壁纸不接收鼠标事件 |
| FR-033 | 鼠标交互模式 | P2 | 可选开启壁纸的鼠标交互模式（与 FR-031 鼠标穿透互补），使网页壁纸等可接收鼠标点击事件 |

### 5.8 用户体验

| 需求 ID | 需求名称 | 优先级 | 描述 |
|---------|----------|--------|------|
| FR-041 | 壁纸预览 | P2 | 支持点击壁纸卡片弹出全屏模态框预览壁纸大图，模态框内提供"设为壁纸"按钮，支持点击遮罩或 ESC 键关闭 |
| FR-042 | 壁纸搜索 | P2 | 支持在壁纸库中按文件名实时搜索过滤壁纸，不区分大小写，清空搜索框恢复显示全部 |
| FR-043 | 加载动画 | P2 | 壁纸列表加载时显示骨架屏占位，缩略图加载时显示占位背景并渐显，提供视觉反馈 |
| FR-044 | 响应式设计 | P2 | 窗口宽度 < 768px 时设置面板改为可折叠抽屉式，壁纸网格列数自适应减少 |
